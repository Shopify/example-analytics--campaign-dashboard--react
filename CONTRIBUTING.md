# Contributing

This repository is a documentation sample. It's the companion code for the [Build a campaign performance dashboard](https://shopify.dev/docs/apps/build/analytics/build-a-campaign-dashboard) tutorial on shopify.dev, and the tutorial renders these files directly.

Because the content is tied to the tutorial, this repository **doesn't accept issues or external contributions**. To report a problem or suggest a change, use the feedback control on the [tutorial page](https://shopify.dev/docs/apps/build/analytics/build-a-campaign-dashboard).

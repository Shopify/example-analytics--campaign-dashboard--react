# Contributing

This repository is a documentation sample. It's the companion code for the [campaign dashboard tutorial series](https://shopify.dev/docs/apps/build/analytics) on shopify.dev, and the tutorial renders these files directly.

Because the content is tied to the tutorial, this repository **doesn't accept issues or external contributions**. To report a problem or suggest a change, use the feedback control on the [tutorial page](https://shopify.dev/docs/apps/build/analytics).
